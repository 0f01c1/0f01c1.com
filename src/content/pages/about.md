I'm a security researcher with a keen interest in enterprise software and web applications. My past work has focused on hypervisors, .NET applications, and web app pentesting. Currently, I'm an Cloud Security Engineer at Wiz where I research how to secure cloud environments.

This blog is a collection of all the bits of knowledge I've gained over the years and anything else I find interesting in the security space.  If you think I've got something wrong in one of my posts, this blog is fully open source and pull requests are always welcome!

`0f01c1` is the x86 opcode for the `vmcall` instruction. It was inspired by my time spent reading the *<a href="https://www.intel.com/content/www/us/en/developer/articles/technical/intel-sdm.html" target="_blank">Intel 64 and IA-32 Architectures Software Developer's Manual</a>* on a previous project.
